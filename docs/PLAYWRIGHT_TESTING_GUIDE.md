# Playwright Testing Guide for QA-Browser Phase

## Overview

This guide explains how to write effective Playwright tests for acceptance criteria validation in the QA-Browser phase. Tests are generated by the `qa_browser_engineer` agent and executed automatically against running applications.

## Key Principles

### 1. Use Accessible Selectors (Not XPath/CSS)

**❌ Bad:**
```typescript
// Brittle CSS selector
await page.click("div.header > button:nth-child(3)");

// Complex XPath
await page.locator("//*[@id='main']/div[2]/button[@class='submit']").click();
```

**✅ Good:**
```typescript
// Use accessible selectors — they're human-friendly and change-resistant
await page.getByRole("button", { name: "Submit" }).click();
await page.getByLabel("Email address").fill("user@example.com");
await page.getByText("Welcome to our app").isVisible();
```

### 2. Test User Flows, Not Implementation Details

**❌ Bad:**
```typescript
// Tests internal state management
const state = await page.evaluate(() => window.__redux_state__);
expect(state.user.logged_in).toBe(true);
```

**✅ Good:**
```typescript
// Tests what the user sees and can do
await expect(page.getByText("Welcome, Alice")).toBeVisible();
await expect(page.getByRole("button", { name: "Logout" })).toBeEnabled();
```

### 3. Write Clear Test Titles Linked to Acceptance Criteria

**❌ Bad:**
```typescript
test("user flow 1", async ({ page }) => {
  // ...
});
```

**✅ Good:**
```typescript
test("AC-001: User can sign up with email and password", async ({ page }) => {
  // Clearly maps to acceptance criterion AC-001
  // ...
});
```

## Test Structure

### Basic Template

```typescript
import { test, expect } from "@playwright/test";

test("AC-001: User can log in with valid credentials", async ({ page }) => {
  // 1. Navigate to the app
  await page.goto("/");

  // 2. Perform actions (mimic user behavior)
  await page.getByLabel("Email").fill("alice@example.com");
  await page.getByLabel("Password").fill("securepassword123");
  await page.getByRole("button", { name: "Sign in" }).click();

  // 3. Assert expected outcomes
  await expect(page.getByText("Welcome, Alice")).toBeVisible();
  await expect(page.getByRole("navigation")).toContainText("Logout");
});
```

### Multi-Page/Multi-Step Test

```typescript
test("AC-003: User can create and view a todo item", async ({ page }) => {
  // Login (setup)
  await page.goto("/login");
  await page.getByLabel("Email").fill("alice@example.com");
  await page.getByLabel("Password").fill("password123");
  await page.getByRole("button", { name: "Sign in" }).click();

  // Navigate to todos
  await page.goto("/todos");

  // Create a todo
  await page.getByRole("button", { name: "New Todo" }).click();
  await page.getByLabel("Title").fill("Buy groceries");
  await page.getByRole("button", { name: "Create" }).click();

  // Verify it appears in the list
  await expect(page.getByText("Buy groceries")).toBeVisible();

  // Click to view details
  await page.getByText("Buy groceries").click();

  // Verify details page
  await expect(page.getByRole("heading")).toContainText("Buy groceries");
});
```

## Accessibility Selectors

### Common Patterns

#### By Role + Name

```typescript
// Button by text
await page.getByRole("button", { name: "Submit" }).click();
await page.getByRole("button", { name: /submit/i }).click();  // Case-insensitive regex

// Heading
await expect(page.getByRole("heading", { level: 1 })).toContainText("Dashboard");

// Link
await page.getByRole("link", { name: "Home" }).click();

// Navigation
await expect(page.getByRole("navigation")).toBeVisible();

// Dialog/Modal
const dialog = page.getByRole("dialog", { name: "Confirm deletion" });
await dialog.getByRole("button", { name: "Delete" }).click();
```

#### By Label

```typescript
// For form inputs
await page.getByLabel("Email address").fill("user@example.com");
await page.getByLabel("Password").fill("secret");
await page.getByLabel("Remember me").check();  // Checkbox
```

#### By Text Content

```typescript
// Exact match
await page.getByText("Welcome").click();

// Partial match
await page.getByText(/welcome/i).click();

// In a specific container
const card = page.locator("article").filter({ hasText: "Product 1" });
await card.getByRole("button", { name: "Add to cart" }).click();
```

#### By Placeholder

```typescript
// Input by placeholder
await page.getByPlaceholder("john@example.com").fill("alice@example.com");
```

### Combining Selectors

```typescript
// Get button inside a specific form
const form = page.locator("form").filter({ hasText: "Login" });
await form.getByRole("button", { name: "Sign in" }).click();

// Get visible elements only
await page.getByRole("button", { name: "Delete" }).isVisible();

// Get nth occurrence
const buttons = page.getByRole("button", { name: "Submit" });
await buttons.nth(0).click();  // First submit button
```

## Assertions

### Common Assertions

```typescript
// Visibility
await expect(element).toBeVisible();
await expect(element).toBeHidden();

// State
await expect(button).toBeEnabled();
await expect(button).toBeDisabled();
await expect(checkbox).toBeChecked();

// Content
await expect(element).toContainText("Expected text");
await expect(element).toHaveText("Exact text");
await expect(page).toHaveTitle("Page Title");

// Form values
await expect(input).toHaveValue("expected value");

// Count
await expect(page.getByRole("button")).toHaveCount(3);

// Attribute
await expect(link).toHaveAttribute("href", "/dashboard");

// Class
await expect(element).toHaveClass("active");
```

## Handling Async Behavior

### Waiting for Elements

```typescript
// Wait for element to appear (auto-retries)
await expect(page.getByText("Loading complete")).toBeVisible();

// Wait for navigation
await page.goto("/login");
await page.getByRole("button", { name: "Sign in" }).click();
await page.waitForURL("/dashboard");

// Wait for API responses
const responsePromise = page.waitForResponse(
  response => response.url().includes("/api/users") && response.status() === 200
);
await page.getByRole("button", { name: "Load users" }).click();
const response = await responsePromise;

// Wait for specific condition
await page.waitForFunction(() => {
  return document.querySelectorAll(".todo-item").length > 0;
});
```

### Timeouts

```typescript
// Default timeout is 5 seconds
await expect(element).toBeVisible();

// Custom timeout
await expect(element).toBeVisible({ timeout: 10000 });  // 10 seconds
```

## Common Test Scenarios

### Login Flow

```typescript
test("AC-001: User can log in", async ({ page }) => {
  await page.goto("/login");

  // Verify login form is visible
  await expect(page.getByRole("heading")).toContainText("Sign In");

  // Fill and submit
  await page.getByLabel("Email").fill("alice@example.com");
  await page.getByLabel("Password").fill("password123");
  await page.getByRole("button", { name: "Sign in" }).click();

  // Verify redirect to dashboard
  await page.waitForURL("/dashboard");
  await expect(page.getByText("Welcome, Alice")).toBeVisible();
});
```

### Form Validation

```typescript
test("AC-005: Form shows validation errors", async ({ page }) => {
  await page.goto("/signup");

  // Submit empty form
  await page.getByRole("button", { name: "Create account" }).click();

  // Verify error messages
  await expect(page.getByText("Email is required")).toBeVisible();
  await expect(page.getByText("Password is required")).toBeVisible();

  // Fix and retry
  await page.getByLabel("Email").fill("alice@example.com");
  await page.getByRole("button", { name: "Create account" }).click();

  // Should not show email error anymore
  await expect(page.getByText("Email is required")).not.toBeVisible();
});
```

### List/Table Interactions

```typescript
test("AC-010: User can view and filter todos", async ({ page }) => {
  await page.goto("/todos");

  // Verify list is loaded
  const todos = page.getByRole("row").filter({ hasText: /todo/i });
  await expect(todos).toHaveCount(5);

  // Filter by status
  await page.getByLabel("Show completed").check();
  await expect(todos).toHaveCount(2);

  // Click to edit
  const firstTodo = todos.first();
  await firstTodo.getByRole("button", { name: "Edit" }).click();
  await expect(page.getByRole("dialog")).toBeVisible();
});
```

### Modal/Dialog

```typescript
test("AC-015: User can confirm deletion", async ({ page }) => {
  await page.goto("/todos");

  // Trigger delete
  await page.getByRole("button", { name: "Delete" }).first().click();

  // Modal appears
  const dialog = page.getByRole("dialog", { name: "Confirm deletion" });
  await expect(dialog).toBeVisible();

  // Confirm
  await dialog.getByRole("button", { name: "Delete" }).click();

  // Modal closes, item removed
  await expect(dialog).not.toBeVisible();
  await expect(page.getByText("3 items")).toBeVisible();  // Was 4
});
```

### Data Validation

```typescript
test("AC-020: API data is correctly displayed", async ({ page }) => {
  // Listen for API response
  const responsePromise = page.waitForResponse(
    response => response.url().includes("/api/profile")
  );
  await page.goto("/profile");
  const response = await responsePromise;

  // Verify API data
  const data = await response.json();
  expect(data.name).toBe("Alice Smith");

  // Verify it's displayed on page
  await expect(page.getByText("Alice Smith")).toBeVisible();
  await expect(page.getByText("alice@example.com")).toBeVisible();
});
```

## Debugging Tests

### Print Debug Information

```typescript
test("AC-001: Debug example", async ({ page }) => {
  await page.goto("/");

  // Log to console
  console.log("Page title:", await page.title());
  console.log("Current URL:", page.url());

  // Print HTML (first 500 chars)
  const html = await page.content();
  console.log(html.substring(0, 500));

  // Get all text on page
  const text = await page.evaluate(() => document.body.innerText);
  console.log("Page text:", text);
});
```

### Screenshots & Videos

```typescript
test("AC-001: Capture screenshot", async ({ page }) => {
  await page.goto("/");

  // Automatic screenshot on failure (configured in playwright.config.ts)
  // Or manual:
  await page.screenshot({ path: "screenshot.png" });

  // Video automatically recorded on failure
  // Or enabled globally in config
});
```

### Step-by-Step Debugging

```typescript
test("AC-001: Step debugging", async ({ page }) => {
  await page.goto("/");
  await page.pause();  // Interactive debugger - press resume to continue

  await page.getByLabel("Email").fill("alice@example.com");
  await page.pause();

  await page.getByLabel("Password").fill("password");
  await page.getByRole("button", { name: "Sign in" }).click();
});
```

```bash
npx playwright test --debug
```

### Run All Tests

```bash
cd /path/to/generated/project
npx playwright test
```

### Run Specific Test

```bash
npx playwright test --grep "AC-001"
npx playwright test tests/e2e/generated/login.spec.ts
```

## Best Practices

### 1. Keep Tests Isolated

Each test should be independent and not rely on other tests:

```typescript
// ❌ Bad: test depends on previous test
test("step 1", async ({ page }) => {
  // login...
});

test("step 2", async ({ page }) => {
  // assumes user is logged in (fails if step 1 doesn't run first)
});

// ✅ Good: each test is self-contained
test("AC-001: User can log in", async ({ page }) => {
  // login...
});

test("AC-002: User can create todo", async ({ page }) => {
  // login (setup), then create todo
});
```

### 2. Avoid Hard Waits

```typescript
// ❌ Bad
await page.waitForTimeout(2000);  // Assume 2 seconds is enough

// ✅ Good: wait for the actual element
await expect(page.getByText("Success")).toBeVisible();
```

### 3. Test Real User Flows

```typescript
// ❌ Bad: testing implementation details
const state = await page.evaluate(() => window.__state__.user.loggedIn);
expect(state).toBe(true);

// ✅ Good: test what user sees
await expect(page.getByRole("button", { name: "Logout" })).toBeVisible();
```

### 4. Use Fixtures for Setup

```typescript
// ✅ Good: reusable authenticated page fixture
type AuthenticatedPage = {
  page: Page;
};

const authenticatedPage = test.extend<AuthenticatedPage>({
  page: async ({ page }, use) => {
    await page.goto("/login");
    await page.getByLabel("Email").fill("alice@example.com");
    await page.getByLabel("Password").fill("password123");
    await page.getByRole("button", { name: "Sign in" }).click();
    await page.waitForURL("/dashboard");

    await use(page);
  },
});

authenticatedPage("AC-002: User can create todo", async ({ page }) => {
  // Already logged in, ready to test
  await page.goto("/todos");
  // ...
});
```

### 5. Meaningful Assertion Messages

```typescript
// ❌ Bad
expect(result).toBe(true);

// ✅ Good
await expect(page.getByText("Form submitted successfully")).toBeVisible(
  { timeout: 5000 }
);
```

## Troubleshooting

### "Element not found"

```typescript
// ❌ Likely causes:
await page.getByRole("button", { name: "Submit" }).click();  // Button doesn't exist or different name

// ✅ Debug:
console.log("Available buttons:", await page.getByRole("button").all());
await page.getByRole("button").first().click();  // Click first button to verify
```

### "Test times out"

```typescript
// ❌ Waiting indefinitely for element that never appears
await page.getByText("Success message").click();

// ✅ Add timeout and handle absence:
try {
  await page.getByText("Success message").waitFor({ timeout: 5000 });
} catch (e) {
  console.log("Success message didn't appear, checking for error");
  console.log(await page.content());
}
```

### "Flaky tests" (random failures)

```typescript
// ❌ Bad: timing-dependent
await page.click("button");
const result = await page.textContent(".result");

// ✅ Good: wait for actual change
await page.click("button");
await expect(page.locator(".result")).toContainText("Expected result");
```
